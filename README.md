# Chatbot + Analytics Dashboard

## Setup Instructions

1. Clone the repository:

```bash
git clone <your-repo-url>
cd <project-folder>
```

2. Install dependencies:

```bash
npm install
```

---

## ▶️ Run the Project

```bash
ng serve
```

Open in browser:

```
http://localhost:4200
```

---

## 📌 Notes

- This project uses Angular 21
- All data is mocked locally
